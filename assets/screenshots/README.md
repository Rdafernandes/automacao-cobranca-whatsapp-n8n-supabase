## Critérios de publicação

Antes de publicar uma imagem, confirme que ela não mostra:

- dados reais de clientes;
- telefones reais;
- URLs privadas;
- tokens ou credenciais;
- IDs reais de grupos, pastas ou workflows;
- conteúdo de conversas reais.
