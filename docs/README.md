# Documentação Técnica

Esta pasta contém a documentação pública do case de automação de cobrança via WhatsApp.

O objetivo é permitir dois níveis de leitura:

- uma leitura executiva para entender o problema, a solução e o valor do projeto;
- uma leitura técnica para avaliar arquitetura, workflows, contratos com banco e regras operacionais.
