# Planejamento

## Objetivo Do Repositório

Apresentar um case técnico de automação de cobrança via WhatsApp, com foco em n8n, Supabase, integrações, auditoria operacional e publicação segura em portfólio público.

## Nome Recomendado

```text
automacao-cobranca-whatsapp-n8n-supabase
```

## Descrição Curta Recomendada

```text
Automação de cobrança via WhatsApp com n8n, Supabase, WHAPI e OpenAI, estruturada como case técnico de portfólio com dados simulados e workflows sanitizados.
```

## Tópicos Recomendados Para GitHub

## Público-Alvo

- Recrutadores técnicos.
- Gestores de operações.
- Empresas buscando especialista em automação.
- Vagas de automação low-code/no-code.
- Vagas com foco em n8n, integrações, processos financeiros e bases operacionais.

## Competências Demonstradas

- Mapeamento de processo operacional.
- Modelagem de estados de cobrança.
- Criação de workflows n8n modulares.
- Integração com APIs externas.
- Uso de banco relacional como fonte de estado.
- Escrita de views e RPCs para filas operacionais.
- Controle de dados sensíveis em publicação pública.
- Criação de simulações para demonstrar projetos reais sem expor clientes.

## Critérios De Qualidade

- Workflows sanitizados e importáveis.
- Dados reais removidos.
- Samples fictícios suficientes para demonstrar o fluxo.
- Documentação clara para avaliação rápida.
- Estrutura de repositório organizada.
- Separação entre visão executiva e documentação técnica.
- Checklist de privacidade antes da publicação.

## Escopo Público

Este repositório foca na automação, nos workflows n8n e no banco Supabase.

Inclui:

- workflows n8n;
- contratos operacionais;
- modelagem Supabase demonstrativa;
- seeds e samples fictícios;
- diagramas, prints e documentação.

Não inclui:

- credenciais reais;
- payloads reais;
- dados de clientes;
- qualquer camada visual ou aplicação fora do n8n/Supabase;
- infraestrutura de produção.
