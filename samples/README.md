# Samples públicos

Esta pasta contém exemplos fictícios para demonstrar a evolução dos dados dentro da automação.

Todos os dados são demonstrativos:

- nomes substituídos por placeholders;
- telefones fictícios;
- documentos fictícios;
- IDs demonstrativos;
- URLs de exemplo.

## Pastas

- `entrada-whatsapp/` - payloads simulados recebidos pela WHAPI.
- `processamento/` - saídas intermediárias da classificação e normalização.
- `cobranca-enviada/` - exemplos de mensagem e registro de envio.
- `comprovantes/` - exemplos fictícios de análise de comprovantes.

## Cenários incluídos

1. Cobrança automática enviada para cliente com duas pendências.
2. Cliente responde com promessa de pagamento.
3. Cliente envia comprovante para validação.
4. Cliente contesta valor/serviço.
